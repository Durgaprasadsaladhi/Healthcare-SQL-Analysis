# Medical Data SQL Analysis Project

## Project Overview
This project focuses on analyzing healthcare and hospital management data using SQL. 
The analysis was performed using relational database concepts such as schemas, primary keys, 
foreign keys, joins, aggregate functions, and subqueries to generate meaningful healthcare insights.

The project simulates a real-world hospital database environment and demonstrates 
strong SQL problem-solving and data analysis skills.
